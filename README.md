# Linux Admin Dashboard

Terminal-Based Linux Admin Dashboard developed using Bash scripting.

## Features

- System Information
- Users and Groups
- File and Directory Manager
- Permission Audit
- Text Analyzer
- Backup Manager
- Report Generation

## How to Run

chmod +x dashboard.sh
./dashboard.sh
